# FishingBucket
FishingBucket is the next-generation of proxy services.

This organization exists to hold and structure the components of FishingBucket

## Description
With a history starting with a quick-and-dirty Tupperbox port for [Fluxer](https://fluxer.com), FishingBucket quickly became one of the most beloved bots within the Fluxer ecosystem. As features piled on and on, it became apparent that this project turned into more than just a mere proxy bot.

FishingBucket aims to be neutral and not favoring any specific use case that may arise from this service, creating opportunities for everyone who may find this service useful to use it without judgement.

Right now, FishingBucket exists on both [Fluxer](https://fluxer.com) and [Discord](https://discord.com).

## Organization
The FishingBucket project is split across different repositories under this organization. Here is a brief table of contents:

| Repository | Description |
|------------|-------------|
| [/FishingBucket](https://github.com/FishingBucket/FishingBucket) | The main service, containing the API server and the code for the bots. |
| [/FishingBucketDocs](https://github.com/FishingBucket/FishingBucketDocs) | User-facing documentation for using FishingBucket. |
| [/FishingBucketWebsite](https://github.com/FishingBucket/FishingBucketWebsite) | The public code for the website and dashboard of FishingBucket. |
